# Подробный разбор `hand/hand.py`

## Вступление
```python
1-3: строка документации — описание задачи (рука, локоть, кулак).
5-6: импорт numpy и PIL.Image для работы с массивами и сохранения кадров.
```

## Палитра и утилита
```python
11-13: shade(color, delta) — смещает компоненты цвета, клиппинг в [0,255].
16-27: константы палитры:
  - SKIN_BASE, OUTLINE_COLOR — базовый тон кожи и цвет контура.
  - UPPER_ARM_COLOR, ELBOW_COLOR, FOREARM_COLOR, PALM_COLOR — оттенки частей руки (через shade).
  - THUMB_COLOR — оттенок большого пальца.
  - PHALANX_SHADES — три смещения для фаланг пальцев.
  - NAIL_COLOR, NAIL_OUTLINE — цвет ногтя и его контур.
```

## NURBS
```python
33-41: basis_function(i, p, u, T) — рекурсивная формула Бура для базисов B-сплайна.
44-61: nurbs_curve(control_points, weights, degree=3, num_samples=100):
  - генерирует равномерный узловой вектор;
  - итерируется по параметру u (с защитой на u_max);
  - собирает числитель/знаменатель по весам и базисам;
  - добавляет точку кривой, если знаменатель не близок к нулю.
```

## Безье
```python
66-75: bezier_curve(control_points, num_samples=50) — де Кастельжо:
  - копирует контрольные точки в float,
  - итеративно смешивает точки для каждого t,
  - результат — список координат кривой.
```

## Рисование примитивов
```python
81-100: draw_line — Брезенхем с толщиной (двойной цикл по wx/wy вокруг центрального пикселя).
103-121: draw_polygon_fill — сканлайн: собирает пересечения рёбер с y, сортирует, заливает попарно.
124-127: draw_curve — рисует ломаную по списку точек через draw_line.
109-120 (вставка): draw_joint_line — поперечная линия сустава: строит перпендикуляр к углу и рисует сегмент.
```

## Трансформации
```python
132-138: rotate_point — поворот точки вокруг центра на угол (рад).
140-141: rotate_points — применяет rotate_point к списку.
```

## Фаланга
```python
146-207: draw_phalanx(..., is_tip=False, bend_amount=0, is_base=False, base_scale=0.5, round_tip=True)
  - 152-162: вычисляет локальные вершины прямоугольника фаланги (p1..p4) по направлению и ширинам.
  - 165-172: задаёт контрольные точки для Безье-скругления боковых граней.
  - 175-176: строит левые/правые кривые (bezier_curve).
  - 179-184: опциональная арка кончика (tip_arc) для округления дистальной фаланги.
  - 187-193: опциональная арка основания (base_arc), если это первая фаланга и нужно плавное «врастание» в ладонь; масштаб радиуса — base_scale.
  - 196-205: собирает полигон фаланги: база → левая кривая → (опционально) кончик → правая кривая (развёрнутая).
  - 207-209: заливает полигон skin, рисует контур обеих кривых outline.
  - 211-230: если это кончик и bend_amount>0.35 — рисует ноготь как отдельную Безье-фигуру, затем заливка и контур ногтя.
  - 232: возвращает конечную точку сегмента (для стыковки следующей фаланги).
```

## Палец (3 фаланги)
```python
217-265: draw_finger(...)
  - 223-224: подбирает оттенки фаланг из PHALANX_SHADES относительно базовой кожи.
  - 227-229: мягкие углы сгиба bend1/2/3 (отрицательные — сгиб внутрь ладони), специально занижены, чтобы кончик не завивался вверх.
  - 232-234: shorten1/2/3 — сокращение видимой длины при сгибе (имитация проекции).
  - 236-245: рисует первую фалангу с base_arc (base_scale=0.15), затем суставную линию (joint_line), сдвигает угол на bend1.
  - 249-256: рисует вторую фалангу, суставную линию, сдвигает угол на bend2.
  - 260-265: рисует дистальную фалангу, без закругления кончика (round_tip=False), чтобы ноготь оставался видим.
```

## Большой палец (3 фаланги)
```python
269-308: draw_thumb(...)
  - 271-274: thumb_lift — подъём против часовой (умеренный), base_angle — базовый разворот ближе к ладони.
  - 276-279: bend_phalanx — малый изгиб между фалангами.
  - 281-282: цвет большого пальца из shade(base_skin, -4).
  - 285-291: первая фаланга с большим base_scale=0.5 (шире у основания), суставная линия, угол + bend_phalanx*0.6.
  - 294-301: вторая фаланга, суставная линия, угол + bend_phalanx.
  - 304-308: третья фаланга без округления кончика (round_tip=False), ноготь рисуется внутри draw_phalanx при достаточном сгибе.
```

## Рука целиком
```python
314-481: draw_hand(canvas, elbow_pos, angle_deg, bend_amount)
  - 320-326: цвета частей руки и контур.
  - 328: angle_rad — угол предплечья.
  - 332-351: локальная геометрия плеча (верхняя часть), Безье-контур; плечо фиксировано вниз (upper_angle=0).
  - 353-367: поворот и смещение плеча к elbow_pos, заливка/контур.

  - 397-409: поворот предплечья на angle_rad, Безье-контуры, заливка/контур.
  - 411-414: wrist_pos — конец предплечья (точка запястья).

  - 448-468: четыре пальца; для каждого: смещение по X, длины/ширины фаланг, базовая точка относительно ладони, вызов draw_finger.
  - 470-480: большой палец: база ближе к ладони, три фаланги через draw_thumb.
```

## Кадр и анимация
```python
483-491: create_frame(angle_deg, bend_amount):
  - создаёт холст 800×700, позиционирует локоть в [450, 350], рисует руку.

495-533: create_animation():
  - 100 кадров, ease in/out (квадратичная интерполяция);
  - angle: 0 → −90 (вниз → влево), bend: 0 → 1 (пальцы из прямых в кулак);
  - сохраняет GIF `./outputs/hand_fist.gif` и PNG `fist_0/50/100.png`.

536-537: точка входа — при запуске генерируется анимация.
```

## Что важно при модификации
- Цвета/контур: блок констант; функция `shade` для тонких корректировок.
- Геометрия пальцев: `fingers_data`, `thumb_lengths/widths`, углы `bend1/2/3`, `bend_phalanx`, флаги `base_scale` и `round_tip`.
- Видимость ногтей: оставляйте `round_tip=False` на дистальной фаланге, и углы сгиба должны быть умеренными (как сейчас).
- Расположение сцены: `create_frame` (`width/height`, `elbow_pos`) и профили движения в `create_animation` (угол, bend, easing).
